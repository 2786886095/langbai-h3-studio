# Langbai H3 Studio 产品需求文档

## 产品定义

面向 Windows 普通 NVIDIA 单卡用户的 MiniMax-H3 一站式视频生成客户端，以“创作意图＋智能预设”替代节点编排。

**原则：** 先创作后技术；默认可运行；生成前给出可执行性结论；错误提供修复动作；专家能力不污染新手界面。

## 已确认约束

| 项目 | 决策 |
|---|---|
| 平台与语言 | Windows 首发、简体中文 |
| 目标硬件 | NVIDIA 单卡 16–24GB，按组合实测标记支持 |
| 后端 | 托管 ComfyUI＋外接 ComfyUI＋可选 MiniMax API |
| 外观 | 默认浅色，支持深色 |
| 发布 | Setup＋GitHub Releases＋应用内更新 |
| 许可证 | Studio 自有代码 Apache-2.0；第三方分别披露 |

## P0 功能

1. **首次启动：** 检测硬件、驱动、磁盘，选择托管/外接环境，推荐模型和保存目录，下载并自检。
2. **创作模式：** 文字、首/尾帧、全模态参考；能力不存在时隐藏或解释。
3. **素材输入：** 拖放、选择、粘贴；显示缩略图/波形、规格、用途和数量限制。
4. **参数：** 核心参数默认可见；高级/专家折叠；中文解释与显存、速度、质量影响。
5. **生成前检查：** 模型、节点、显存、磁盘、路径、后端及隐私；问题提供一键修复。
6. **任务队列：** 单 GPU 串行，阶段进度、取消、重试、崩溃恢复和完成预览。
7. **模型中心：** 推荐、已安装、下载、本地导入；续传、速度、ETA、哈希和许可证。
8. **加速插件：** 能力分类、兼容/冲突、来源、验证级别、安装快照和回滚。
9. **运行环境：** 托管环境启动/修复/版本切换；外接环境无副作用探测。
10. **本地/API：** 本地素材不上传；API 模式持续标识上传范围；密钥进 Credential Manager。
11. **应用更新：** 说明、大小、下载进度、签名/哈希、失败回滚。

## 核心流程验收

安装 → 硬件检测 → 推荐环境 → 下载/关联模型 → 创作 → 输入素材/文字 → 选择预设和路径 → 生成前检查 → 队列 → 预览。

验收标准：不打开终端、不编辑 JSON、不接触节点 ID；首次提交不超过 8 个关键决策点。

## 信息架构

开始创作、生成记录、作品、模型中心、加速插件、工作流（专家入口）、设置（运行环境/保存/API/更新/诊断）。

## 明确边界

- 不承诺所有 16GB 显卡可运行全部 H3 配置。
- 不承诺自动兼容任意节点仓库；承诺公开适配协议和代表性插件验证。
- 本地模式不宣称拥有尚未开源的官方 Context-IR/2K 能力。

## 指标

首次自检/生成成功率、安装到提交时长、OOM 修复成功率、下载续传通过率、外接 ComfyUI 探测成功率、无需技术日志的故障解决率、插件健康检查与回滚成功率。
